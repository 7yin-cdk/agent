# Task: Weather Query

---

## Task Metadata

**Task Name**

Weather Query

**Description**

查询指定城市的实时天气信息。

该任务依赖天气查询工具获取实时数据，不允许依赖模型已有知识生成天气结果。

---

## Task Objective

完成用户的天气查询请求，并返回准确的实时天气信息。

完成任务需要满足以下条件：

- 正确识别用户需要查询的城市；
- 使用天气查询工具获取实时天气；
- 根据工具返回结果生成自然语言回答。

---

## Task Knowledge

### 城市识别

用户可能采用以下方式描述城市：

- 北京天气怎么样
- 上海现在热吗
- 杭州今天下雨吗
- 查询广州天气

如果无法唯一确定城市，应向用户询问需要查询哪个城市。

不得自行猜测城市。

---

### 天气信息来源

天气属于实时数据。

模型自身知识不能作为天气依据。

所有天气信息必须来自天气查询工具。

---

## Task Workflow

执行当前任务时，应遵循以下流程：

### Step 1

分析用户请求。

判断是否明确包含城市名称。

---

### Step 2

如果没有城市名称：

结束当前执行，

询问用户需要查询哪个城市。

不得调用工具。

---

### Step 3

如果已经获得城市名称：

调用天气查询工具。

---

### Step 4

等待工具返回结果。

根据返回结果回答用户。

不得修改工具返回的数据。

---

### Step 5

如果工具失败：

告知用户查询失败，

建议稍后重试。

---

## Tool Specification

当前任务可使用如下工具。

### Tool

name

getWeather

description

根据城市名称查询实时天气。

### Parameters

```json
{
  "city": "string"
}
```

参数说明：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| city | string | 是 | 城市名称，例如：北京、上海、杭州 |
